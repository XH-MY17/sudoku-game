# 数独游戏生成与求解

> 纯 Python 实现的数独：随机生成题目、唯一解校验、图形化棋盘显示、交互式解题。

作者：熊虎（重庆工商大学派斯学院 · 软件工程）

---

## 功能特性

- **生成数独解**：基于回溯算法生成完整合法的数独终盘
- **生成数独谜题**：按难度挖空，保证题目有解
- **合法性校验**：实时检查填入数字是否违反数独规则（行 / 列 / 宫）
- **完成度检测**：判断当前棋盘是否已正确完成
- **棋盘显示**：带分隔线的图形化棋盘输出，识别更直观

## 快速开始

```bash
python sudoku.py
```

> 无需任何第三方依赖，标准库即可运行。
